# 🎮 Tic-Tac-Toe

Game Tic-Tac-Toe sederhana menggunakan **C++** dan **Raylib**.

Project ini dibuat sebagai project pembelajaran untuk mempraktikkan **Object-Oriented Programming (OOP)**, game logic, GUI, dan penggunaan library eksternal dalam C++.

## ✨ Fitur

- 🧑 Pemain melawan Bot
- ❌ Pemain menggunakan `X`
- ⭕ Bot menggunakan `O`
- 🎲 Bot memilih posisi secara acak
- ⏱️ Delay sebelum Bot bergerak
- 🏆 Deteksi kemenangan
- 🤝 Deteksi seri
- 🔄 Tombol Play Again
- 🚪 Tombol Exit
- 🖱️ Kontrol menggunakan mouse
- 🖥️ GUI menggunakan Raylib
- ✨ X dan O dibuat tebal agar lebih mudah dilihat

## 🛠️ Teknologi

- C++
- Raylib
- MSYS2 UCRT64
- MinGW-w64
- Git / GitHub
